IS 9.4.1.2 Name, Role, Value Frontend Dev
Medium 3–5 days 371 issues 44 pages
▶
What to fix
Every interactive element must have an accessible name, correct role, and communicate state changes. Use ARIA attributes where native HTML semantics are insufficient.
Code example
<!-- Button without text -->
<button aria-label="Close dialog" type="button">
  <svg aria-hidden="true">...</svg>
</button>

<!-- Custom dropdown -->
<div role="combobox" aria-expanded="false" aria-haspopup="listbox"
     aria-labelledby="city-label" tabindex="0">
  ...
</div>

<!-- Toggle button -->
<button aria-pressed="false" id="darkmode-toggle">
  Dark Mode
</button>
How to test
  • Audit with axe DevTools — zero "name, role, value" failures
  • Test every custom widget with NVDA in browse mode

IS 9.2.4.4 Link Purpose (In Context) Content + Frontend Dev
Medium 2–3 days 58 issues 32 pages
▶
What to fix
Replace vague link text ("click here", "read more", "here") with descriptive text. For icon-only links, add aria-label. For links opening in new tabs, warn users.
Code example
<!-- Bad -->
<a href="/home-loans">Click here</a>
<a href="/blog/post">Read more</a>

<!-- Good -->
<a href="/home-loans">Check home loan eligibility</a>
<a href="/blog/post">Read more about improving your CIBIL Score</a>

<a href="https://youtube.com/..." target="_blank" rel="noopener"
   aria-label="Watch CIBIL explainer video (opens in new tab)">
  Watch video
  <span class="sr-only">(opens in new tab)</span>
</a>
How to test
  • Extract all links via screen reader Link List (NVDA: Insert+F7)
  • Every link must make sense out of context

IS 9.1.4.3 Contrast (Minimum) UI/UX + Frontend Dev
Medium 2–4 days 44 issues 44 pages
▶
What to fix
Ensure all text meets WCAG contrast ratios: 4.5:1 for normal text, 3:1 for large text (18pt/14pt bold). Check placeholder text, disabled states, and overlaid text on images.
Code example
/* Current failing example */
color: #999; /* 2.8:1 on white — FAIL */

/* Fix: darken text or lighten background */
color: #6b7280; /* 4.6:1 on white — PASS */

/* Placeholder text */
::placeholder { color: #6b7280; } /* must be 4.5:1 */

/* Text on hero image — add overlay */
.hero { background: linear-gradient(rgba(0,0,0,.55), rgba(0,0,0,.55)), url(hero.jpg); }
How to test
  • Use browser DevTools Accessibility panel to check contrast
  • Test all text colours with https://webaim.org/resources/contrastchecker/

IS 9.2.4.1 Bypass Blocks Frontend Dev
Easy 0.5 days 44 issues 44 pages
▶
What to fix
Add a visible skip link as the very first focusable element. It can be visually hidden until focused. Ensure the target id exists on every page.
Code example
<!-- In <head> -->
<style>
.skip-link {
  position: absolute;
  top: -40px;
  left: 0;
  background: #0f2744;
  color: white;
  padding: 8px 16px;
  z-index: 9999;
  border-radius: 0 0 6px 0;
  font-weight: 600;
  transition: top .2s;
}
.skip-link:focus { top: 0; }
</style>

<!-- First element in <body> -->
<a class="skip-link" href="#main-content">Skip to main content</a>

<!-- On every page template -->
<main id="main-content" tabindex="-1">...</main>
How to test
  • Press Tab on page load — skip link must appear
  • Press Enter — focus must move to main content
  • Navigation must not be traversed again after skip

IS 9.1.4.4 Resize Text Frontend Dev
Easy 1 day 29 issues 29 pages
▶
What to fix
Remove any CSS that prevents text scaling. Use relative units (rem/em) for font sizes. Never use user-scalable=no in the viewport meta tag.
Code example
<!-- Remove this -->
<meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no">

<!-- Use this -->
<meta name="viewport" content="width=device-width, initial-scale=1">

/* Use rem instead of px for body text */
body { font-size: 1rem; }       /* 16px base */
p    { font-size: 0.875rem; }   /* 14px */
small{ font-size: 0.75rem; }    /* 12px minimum */

/* Indic scripts need larger minimum */
:lang(hi), :lang(ta), :lang(te), :lang(bn) { font-size: 1rem; } /* 16px min */
How to test
  • Set browser zoom to 200% — text must reflow without horizontal scroll
  • Test on mobile with system font size set to Largest

IS 9.2.1.1 Keyboard Frontend Dev
Hard 5–8 days 6 issues 6 pages
▶
What to fix
Replace all <a href="#"> used as JS triggers with <button>. Ensure every interactive element is reachable and operable by keyboard alone. Test: Tab, Shift+Tab, Enter, Space, Arrow keys.
Code example
<!-- Wrong: anchor as button -->
<a href="#" onclick="openMenu()">Menu</a>

<!-- Right: use button -->
<button type="button" aria-expanded="false" aria-controls="menu-panel">Menu</button>

<!-- Dropdown keyboard pattern -->
<button aria-haspopup="true" aria-expanded="false" id="nav-trigger">
  Products
</button>
<ul role="menu" aria-labelledby="nav-trigger" hidden>
  <li role="menuitem"><a href="/consumer">Consumer</a></li>
</ul>
How to test
  • Disconnect mouse entirely
  • Navigate entire page using only keyboard
  • Every action achievable with mouse must work with keyboard

IS 9.2.5.5 Target Size UI/UX + Frontend Dev
Medium 2–3 days 44 issues 44 pages
▶
What to fix
All clickable/tappable targets must be at least 44×44 CSS pixels. Increase padding on small buttons, links, and checkboxes rather than increasing font size.
Code example
/* Minimum touch target size */
.btn, a, button {
  min-height: 44px;
  min-width: 44px;
  padding: 10px 16px;
  display: inline-flex;
  align-items: center;
}

/* Small inline links — use padding for hit area */
.nav-link {
  padding: 11px 8px;
  line-height: 1;
}

/* Checkbox/radio —larger click area */
input[type="checkbox"] { width: 20px; height: 20px; }
label { min-height: 44px; display: flex; align-items: center; gap: 8px; }
How to test
  • Test on mobile device with finger
  • Use Chrome DevTools touch simulation
  • No target smaller than 44×44px

IS 9.1.3.5 Identify Input Purpose Frontend Dev
Easy 1 day 17 issues 17 pages
▶
What to fix
Add autocomplete attributes to all personal data inputs. This helps users with cognitive disabilities and motor impairments auto-fill forms.
Code example
<input type="text"  name="name"     autocomplete="name">
<input type="email" name="email"    autocomplete="email">
<input type="tel"   name="mobile"   autocomplete="tel">
<input type="text"  name="pan"      autocomplete="off">
<input type="text"  name="otp"      autocomplete="one-time-code">
<input type="date"  name="dob"      autocomplete="bday">
<input type="password" name="pass"  autocomplete="current-password">
How to test
  • Open browser autofill — fields must populate correctly
  • Test with a password manager for password fields

IS 9.1.3.1 Info and Relationships Frontend Dev
Medium 3–5 days 12 issues 6 pages
▶
What to fix
Use semantic HTML for all data relationships. Add scope attributes to <th> cells. Wrap radio/checkbox groups in <fieldset><legend>. Ensure landmark regions (main, nav, footer) are present.
Code example
<!-- Data table -->
<table aria-label="CIBIL Score history">
  <caption>Monthly score breakdown</caption>
  <thead>
    <tr><th scope="col">Month</th><th scope="col">Score</th></tr>
  </thead>
  <tbody>...</tbody>
</table>

<!-- Radio group -->
<fieldset>
  <legend>Select subscription plan</legend>
  <label><input type="radio" name="plan" value="basic"> Basic</label>
  <label><input type="radio" name="plan" value="premium"> Premium</label>
</fieldset>
How to test
  • Screen reader must announce table headers for each cell
  • Fieldset legend must be read when entering radio groups
  • Landmark nav must be announced on page entry

IS 9.3.2.2 On Input Frontend Dev
Easy 1 day 6 issues 6 pages
▶
What to fix
Warn users before opening a new browser window or tab. Add visible text or a visually-hidden span, or update the aria-label.
Code example
<!-- Option 1: visually-hidden text -->
<a href="https://youtube.com/..." target="_blank" rel="noopener">
  Watch video
  <span class="sr-only">(opens in new tab)</span>
</a>

<!-- Option 2: aria-label override -->
<a href="/pdf/report.pdf" target="_blank" rel="noopener"
   aria-label="Download annual report PDF (opens in new tab)">
  Annual Report
</a>

/* Reusable utility class */
.sr-only {
  position:absolute;width:1px;height:1px;
  padding:0;margin:-1px;overflow:hidden;
  clip:rect(0,0,0,0);white-space:nowrap;border:0;
}
How to test
  • Screen reader must announce "(opens in new tab)" for all external links
  • Visually impaired users must not be surprised by new window
