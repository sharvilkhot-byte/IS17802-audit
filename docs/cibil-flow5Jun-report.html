IS 9.4.1.2 Name, Role, Value Frontend Dev
Medium 3–5 days 3 issues 1 page
▶
What to fix
Every interactive element must have an accessible name, correct role, and communicate state changes. Use ARIA attributes where native HTML semantics are insufficient.
Code example
<!-- Button without text -->
<button aria-label="Close dialog" type="button">
  <svg aria-hidden="true">...</svg>
</button>

<!-- Custom dropdown -->
<div role="combobox" aria-expanded="false" aria-haspopup="listbox"
     aria-labelledby="city-label" tabindex="0">
  ...
</div>

<!-- Toggle button -->
<button aria-pressed="false" id="darkmode-toggle">
  Dark Mode
</button>
How to test
  • Audit with axe DevTools — zero "name, role, value" failures
  • Test every custom widget with NVDA in browse mode

IS 9.1.4.3 Contrast (Minimum) UI/UX + Frontend Dev
Medium 2–4 days 1 issue 1 page
▶
What to fix
Ensure all text meets WCAG contrast ratios: 4.5:1 for normal text, 3:1 for large text (18pt/14pt bold). Check placeholder text, disabled states, and overlaid text on images.
Code example
/* Current failing example */
color: #999; /* 2.8:1 on white — FAIL */

/* Fix: darken text or lighten background */
color: #6b7280; /* 4.6:1 on white — PASS */

/* Placeholder text */
::placeholder { color: #6b7280; } /* must be 4.5:1 */

/* Text on hero image — add overlay */
.hero { background: linear-gradient(rgba(0,0,0,.55), rgba(0,0,0,.55)), url(hero.jpg); }
How to test
  • Use browser DevTools Accessibility panel to check contrast
  • Test all text colours with https://webaim.org/resources/contrastchecker/

IS 9.2.5.5 Target Size UI/UX + Frontend Dev
Medium 2–3 days 4 issues 4 pages
▶
What to fix
All clickable/tappable targets must be at least 44×44 CSS pixels. Increase padding on small buttons, links, and checkboxes rather than increasing font size.
Code example
/* Minimum touch target size */
.btn, a, button {
  min-height: 44px;
  min-width: 44px;
  padding: 10px 16px;
  display: inline-flex;
  align-items: center;
}

/* Small inline links — use padding for hit area */
.nav-link {
  padding: 11px 8px;
  line-height: 1;
}

/* Checkbox/radio —larger click area */
input[type="checkbox"] { width: 20px; height: 20px; }
label { min-height: 44px; display: flex; align-items: center; gap: 8px; }
How to test
  • Test on mobile device with finger
  • Use Chrome DevTools touch simulation
  • No target smaller than 44×44px
